# Changelog

## 0.1.0

First release.

- 12 tools: publish text, video, photos and documents (from files uploaded in Dify or URLs; now, scheduled or queued,
  with first comment and network settings); post status; retry failed networks; list profiles; history; analytics
  (profile, history, one post); scheduled posts and cancelling; AI captions.
- Posting tools wait for each network's result. Errors come back as text the model can act on.
- The API key is checked against Reelspan when you save it.
