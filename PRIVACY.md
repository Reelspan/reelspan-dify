# Privacy

This plugin sends what you ask it to publish (text, captions, media files or links, and post settings) and your
Reelspan API key to the Reelspan API at `https://api.reelspan.com` (or the base URL you set), so Reelspan can publish
it to the social networks you choose. It reads back post results, history, scheduled posts and analytics for your
account. The plugin itself stores nothing and sends nothing anywhere else.

How Reelspan handles that data: [reelspan.com/privacy](https://reelspan.com/privacy). Questions:
support@reelspan.com.
